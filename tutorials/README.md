## Conformance notes

- **Standalone carrier (ST1–ST8):** the primary path performs no clone, repository install, or repository import. Section 2 embeds the repository's 3 modules (`pipeline.py`, `samples.py`, `metrics.py`) verbatim in topological dependency order (each tagged `metadata.dimer.embedded_module`; the only rewrites make `DEFAULT_WEIGHTS_DIR` working-directory-relative and remove internal relative package imports), Section 3 carries the 6-file snapshot manifest inline and asserts it against the module's own identity constants before anything is fetched, and Section 1 carries the exact `pyproject.toml` runtime pins. `metadata.dimer.generated_from` records the repository, the revision, the module SHA-256 digests, and the generator version.
- **Parity (PAR1–PAR4):** `tests/test_notebook_parity.py` and `tools/validate_release_assets.py` fail when the carried modules, the inline manifest, or the inline pins differ from the repository, or when the notebook is not byte-identical to the generator's output.
- **Model acquisition (MOD1–MOD9):** `stage_missing_files(WEIGHTS_DIR, allow_download=True)` fetches only the manifest entries that are absent, from the Hugging Face Hub at the immutable revision (never `main`); `verify_snapshot` re-hashes every entry; `GeneformerPipeline.from_pretrained(weights_dir=...)` then loads with `local_files_only=True`, `trust_remote_code=False` and `use_safetensors=True`. The upstream `training_args.bin` torch pickle and the repository's other checkpoints (V1-10M, V2-316M, the cancer-tuned variant) are not in the manifest and are never loaded (MOD9). The notebook never imports `transformers`, `huggingface_hub` or `safetensors` for model work outside the carried module cells.
- **Deserialization boundary (§20):** Geneformer's tokenizer is three Python pickles. They are digest-verified as part of the snapshot and then loaded through `RestrictedUnpickler`, which refuses every global except the numpy scalar/dtype classes the median dictionary legitimately contains; the notebook states this before the dictionaries are read, and a unit test pickles a callable and asserts the refusal. The loaded token dictionary is shape-checked against the `vocab_size` in `config.json`.
- **Stages (§4.1):** `generate_sample_dataset` / `load_byod_dataset` (sample acquisition) → `validate_dataset` with the vocabulary (validation, including how many genes per cell are encodable) → `split_dataset` (stratified train/validation/test) → `rank_value_encode` read cell by cell → `pipe.embed` (representations) → `majority_baseline` + `library_size_baseline` (baselines fitted on the training split only) → `pipe.adapt` (bounded gradient fine-tuning, real on the default path, RUN7/FT2) → `pipe.evaluate` (held-out metrics) → `pipe.classify` (new-cell inference) → `pipe.save_artifact` (export + provenance) → `GeneformerPipeline.from_artifact` (fresh-boundary reload and parity assertion).
- **Score semantics (UNC1–UNC4):** the per-class scores are softmax outputs of a head trained on a small labelled set, not calibrated probabilities; the only decision rule is argmax, and deployment thresholding is the caller's. Embeddings are labelled as representations with no intrinsic metric (EVAL9).
- **Baselines and evidence (EVAL6/EVAL10/EVAL11):** majority-class and library-size baselines are computed on the same test split as the model, and every metric is labelled as tutorial sample-sanity evidence from one seeded holdout with no dispersion estimate. The synthetic cells share their library size and detected genes by construction, which is what makes the comparison informative. The notebook also explains the under-trained regime — high AUROC with chance accuracy — that an earlier schedule produced.
- **Split integrity (SPL1–SPL8):** the split is explicit, stratified and seeded; validation metrics are used for per-epoch monitoring only and the final epoch's weights are kept, so the test split is never used for selection. The notebook states that random splitting assumes independent cells and that real data needs a donor- or batch-level split.
- **Ceilings (VAL6):** `MAX_INPUT_TOKENS = 4096` / `MAX_GENES_PER_CELL = 4094`, `MIN_DETECTED_GENES = 10`, `MAX_CELLS_PER_CALL = 32` and the record and class minimums and maximums are printed from the dataset manifest before the model runs, and every encoding reports its dropped and truncated genes.
- **BYOD (DAT10–DAT19):** `USE_BYOD` defaults to `False` so the sample path never opens an upload dialog; when enabled, user cells flow through the same validation, split, baselines, encoding, adaptation, evaluation, inference, export and reload cells. The expected schema, the human-only identifier requirement and the privacy guidance are stated in the Prerequisites and in Section 4, and the sample dataset is written to `outputs/geneformer_single_cell_sample_dataset.csv` as a template.
- `tools/validate_release_assets.py` performs source validation only. It does not satisfy the
  clean-runtime execution requirement; a release review must confirm that a recorded clean run in
  `docs/release-verification.md` matches the notebook revision under review before the status is
  promoted to `Release-grade`.
